## Deferral cleanup findings

No orphaned Xcode targets, entitlements, App Group keys, or notification action categories were found for Watch, Widgets, or Live Activities anywhere in the native tree — deferral cleanup is otherwise clean. The one loose end is **NATIVE-018**: Help Center and What's New content still describes Dynamic Island playback controls as if they shipped, which is a stale-copy defect distinct from the (correctly clean) code-level deferral.
