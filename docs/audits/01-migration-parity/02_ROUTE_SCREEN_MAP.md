# 02 — Legacy Route to Native Destination Map

All 81 legacy `app/` route/source files accounted for. Compiled from five parallel research slices (core nav/tabs, content detail/player, settings/profile/account, onboarding/info, contact/submit wizards) plus a cross-cutting review of `DeepLinkRouter.swift`, `ContentView.swift`, and the legacy docs/Temp audit trail. Before merging, the compiling pass independently re-verified 8 of the highest-severity claims directly against source (not relay text alone): `EditProfileView.swift`'s dead `displayName` state, `EpisodeDetailView.swift`'s `isTitleFocused` never-set bug, `ItunesAPI.swift`'s hardcoded `entity=software`, `SubmitAppView.swift`'s 3-field `isValid` gate, the `GuidelinesCheckState`/`ComposeIntelligenceState` distribution across compose variants, `OpenSourceView.swift`'s single-dependency disclosure, `submit-app.tsx`'s redirect-stub pattern, and `ComposeReplyView`'s guidelines wiring — all confirmed exactly as reported. `submit-app.tsx` was read directly after being omitted from its slice's original relay. A few rows carry lower confidence where a slice reported only group-level findings rather than a line-by-line read.

## Highest-priority findings from this map

1. **submit-wizard/notes.tsx → MISSING, Critical** — the accessibility-assessment form's validation is essentially absent (`isValid` checks only 3 unrelated fields). This is the single most severe finding in the entire audit, independently confirmed by both this map and the feature-parity ledger (SUBMIT-005).
2. **submit-wizard/platform.tsx → MISSING, Critical** — no macOS/tvOS submission path exists; `ItunesAPI.swift` hardcodes iOS-only search. Confirms SUBMIT-003.
3. **submit-wizard/confirm.tsx → MISSING, Critical** — no duplicate-app check exists anywhere. Confirms SUBMIT-004.
4. **open-source.tsx → REGRESSION, High** — a legal-disclosure screen collapsed to one dependency; needs explicit legal/compliance sign-off before release, not an assumption that it's correct.
5. **compose.tsx → REGRESSION, Medium** — 5 of 7 native compose variants don't wire the Guidelines/Translation/Writing-Tools helpers that legacy applied uniformly across all compose contexts.
