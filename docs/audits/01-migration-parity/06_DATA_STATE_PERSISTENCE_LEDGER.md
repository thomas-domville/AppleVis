## Headline findings

1. **No Expo→native data migration exists** (DATA-047), confirmed by exhaustive grep — Critical severity. Every local preference, saved/followed item, playback position, and cached download resets to native defaults on first launch, even for a user on the same iCloud account with sync previously enabled.
