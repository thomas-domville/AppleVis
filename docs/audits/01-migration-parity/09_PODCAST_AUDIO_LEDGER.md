## Headline findings

1. **Real regression**: episode duration always renders as "0 minutes" pre-play on native (PODCAST-035) — a literal `duration: 0` in the mapper, no fallback caching.
2. **Two confirmed legacy stubs now genuinely implemented in native**: Voice Boost and Trim Silence do real DSP in native, whereas legacy's own native module explicitly stubbed both ("operates in a stub mode that logs intent") — a substantive native improvement, not mere parity (PODCAST-024, PODCAST-026).
3. **Chapter parsing architecture changed**: native relies entirely on Drupal's `field_chapters` with no ID3 CHAP fallback like legacy had — a real gap for episodes lacking server-side chapter metadata (PODCAST-032).
4. **Magic Tap scope narrowed**: only one global handler vs. legacy's three per-context handlers; flagged for device verification since SwiftUI sheet accessibility-tree isolation makes root-level firing uncertain from source alone (PODCAST-034).
5. Interruption/route-change handling, queue persistence, resume-rewind default, and sleep-timer wiring were all previously buggy-or-missing and are now confirmed fixed and complete (cross-referenced against real commits `da6c7ef`, `bd6b6f2`, `a94cdc3`).
