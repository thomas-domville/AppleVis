# How-To Library: proposed topics (Phase 1, for review)

Prepared 2026-10-08, with iOS 27 as the current version (released 14 September 2026). Nothing is written yet. This is the list for Thomas to review: add, cut, or reorder before writing starts.

## How each article will work

- One task per article, titled the way people ask: "How do I …?"
- A sentence on what it does, the exact Settings path, then numbered steps.
- VoiceOver steps first. For example, using the Actions rotor instead of dragging. Touch, braille, and keyboard notes where they differ.
- Written in AppleVis's own words. Apple's guides are only used to check facts, never copied.
- Each article is marked with the iOS version it was checked on. The baseline is **iOS 27**, which is current as of September 2026. Older-version notes appear only where many people are still on iOS 26.
- Each links to the related AppleVis guide or podcast when there is one. It also links to Apple's page, through Need More Help in Ask the Mouse.
- Some honest answers are "you can't". For example, iOS can't rename an app, but Shortcuts can make a renamed shortcut to it. Those say so plainly and give the closest option.
- Help is translated automatically while the app runs, so there's no translation work.

Key: **[NEW]** new article. **[EXPAND]** Help has part of this already (the existing article is named). **[iOS 27]** new or changed in iOS 27. **[iOS 26]** arrived in iOS 26 and is still current. **[CHECK]** a fact to confirm carefully while writing.

## How we'll pick the order

1. Real questions the Mouse couldn't answer: its gap reports and Send Notes.
2. The most-read AppleVis guides and the most common forum questions.
3. What changed in iOS 27, which people are asking about right now: Image Explorer, Text Exploration, braille predictions, the Liquid Glass slider, the Siri app, and auto subtitles. Then iOS 26 features that are still new to many people: Braille Access and Call Screening.

**Suggested first batch, about 20 articles:**
- iOS 27 VoiceOver: Image Explorer, Text Exploration, hint verbosity, and the pronunciation dictionary.
- Home Screen: move apps, folders, lock or hide apps, rename (no).
- Wi-Fi and Bluetooth: pairing, forgetting, and troubleshooting.
- VoiceOver: rate, voice, rotor, gestures, Screen Curtain.
- Braille: connect, tables, commands, Braille Access.
- Low vision: text size, Reduce Transparency.
- Calls: Call Screening.
